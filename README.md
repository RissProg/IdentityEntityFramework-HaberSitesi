
# 📰 Identity Entity Framework Haber Sitesi

Bu proje, **ASP.NET Core MVC** altyapısı kullanılarak geliştirilmiş, güvenli kimlik doğrulama mekanizmalarına (ASP.NET Core Identity) ve güçlü bir veritabanı yönetim katmanına (Entity Framework Core) sahip dinamik bir haber platformudur.

---

## 🚀 Özellikler

- **🔒 ASP.NET Core Identity:** Güvenli kullanıcı kayıt, giriş (login/logout), parola yönetimi ve oturum açma işlemleri.
- **👥 Rol Tabanlı Yetkilendirme (RBAC):** Admin, editör ve standart kullanıcı rolleri ile yönetim paneli ve içerik erişim kontrolü.
- **💾 Entity Framework Core (Code-First):** İlişkisel veritabanı yönetimi, migration yapıları ve LINQ tabanlı veri sorgulama.
- **📰 Dinamik İçerik Yönetimi:** Haber ekleme, güncelleme, silme, kategori yönetimi ve yayına alma işlemleri.
- **📱 Responsive Tasarım:** Bootstrap altyapısıyla tüm mobil ve masaüstü cihazlara uyumlu modern arayüz.

---

## 🛠️ Kullanılan Teknolojiler

- **Backend:** C#, ASP.NET Core MVC
- **ORM & Veritabanı:** Entity Framework Core, MS SQL Server
- **Güvenlik:** ASP.NET Core Identity
- **Frontend:** HTML5, CSS3, Bootstrap, JavaScript
